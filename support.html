Set up

  1. In AppBell, tap Turn on notifications and copy your URL.
  2. In App Store Connect, open your app → App Information → App Store Server Notifications, and paste the URL as the Production Server URL (and the Sandbox Server URL to test), Version 2.
  3. Back in AppBell, tap Send a test notification.

Frequently asked questions

  • No notification arrives. Check that notifications are allowed for AppBell in iOS Settings, and that the URL in App Store Connect is the one shown in the app, set to Version 2.
  • I already use another service for these notifications. Apple allows one URL per app: pasting AppBell's URL replaces the existing one.
  • Amounts look different from my proceeds. AppBell shows customer prices including tax, refunds deducted, converted with the European Central Bank's daily rates.
  • Restore AppBell Pro. App settings → AppBell Pro → Restore purchases.

Mise en route

  1. Dans AppBell, touchez Activer les notifications et copiez votre URL.
  2. Dans App Store Connect, ouvrez votre app → Informations sur l'app → Notifications du serveur App Store, et collez l'URL comme URL du serveur de production (et de Sandbox pour tester), version 2.
  3. De retour dans AppBell, touchez Envoyer une notification de test.

Questions fréquentes

  • Aucune notification n'arrive. Vérifiez que les notifications sont autorisées pour AppBell dans les Réglages d'iOS et que l'URL dans App Store Connect est bien celle affichée dans l'app, en version 2.
  • J'utilise déjà un autre service pour ces notifications. Apple n'accepte qu'une URL par app : coller celle d'AppBell remplace l'existante.
  • Les montants diffèrent de mes revenus. AppBell affiche les prix clients TTC, remboursements déduits, convertis avec les taux quotidiens de la Banque centrale européenne.
  • Restaurer AppBell Pro. Réglages de l'app → AppBell Pro → Restaurer les achats.
